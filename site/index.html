How it works

Running in five minutes.

  1. 1

    Run it

    Run it on your own server.

    terminal 
    $ git clone https://github.com/openstuff-dev/open-announce
$ cd open-announce && docker compose up -d
  2. 2

    Add your systems

    Add each app, then paste three elements and a config file into it: npm i @openstuff-dev/announce.

  3. 3

    Publish

    Write a message, pick who and where, and it shows on their next page view.

FAQ

Questions people ask first

Is it free?

Yes. OpenAnnounce is open source under the MIT licence, so self-hosting costs nothing but your server.

Can I self-host it?

Yes. Clone the repository and run docker compose up -d: one app container and Postgres, configured with environment variables.

Where is my data?

In your own Postgres. Admins can export a tenant as one JSON file at any time, and import it on another server.

Does it work with my framework?

Yes. The elements are standard web components, so they work in Angular, React, Vue, Svelte or a plain HTML page, with no framework of their own.
